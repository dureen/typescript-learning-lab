# TypeScript Learning Lab

Hands-on TypeScript tutorial repository divided into **Beginner**, **Intermediate**, and **Advanced** levels.

**Last updated:** October 1, 2026

Each lesson contains:
- Clear explanation
- Runnable TypeScript example code
- Practice exercises
- Corresponding unit tests (in `/tests`)

## Structure

```
typescript-learning-lab/
├── beginner/          # Fundamentals
├── intermediate/      # Intermediate concepts
├── advanced/          # Advanced topics
├── exercises/         # Extra practice exercises
├── tests/             # Unit tests
└── projects/          # Small complete projects
```

## How to use

1. Clone the repository
2. Install dependencies
3. Run any lesson with `npx ts-node`

```bash
git clone https://github.com/dureen/typescript-learning-lab.git
cd typescript-learning-lab
npm install

# Example: run a beginner lesson
npx ts-node beginner/01-hello-world/main.ts
```

## Requirements

- Node.js 18+
- TypeScript 5+
